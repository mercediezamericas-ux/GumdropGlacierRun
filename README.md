##How to Play 
This game is a multi-level game so you have to make it through all the levels to win. 
The first level is simple, avoid the lollypops to get to the portal.
Once you get in the portal you are now faced with a horizontal jump land (tbd) 
Once you reach a certain point then you get to achieve the next level. 
Then you reach the third and final level. The 1 v 1 verses the bad gum drop guy who has been following you around the map this entire time.
